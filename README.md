# Bankist Landing Page

A modern and interactive banking landing page built with **HTML, CSS, and JavaScript**.  
This project focuses on creating a smooth user experience with modern frontend techniques.

## ✨ Features

- Smooth scrolling navigation
- Sticky navigation bar
- Responsive modal window
- Tabbed content component
- Menu fade animations
- Lazy loading images
- Section reveal animations
- Image slider with navigation and dots
- Back-to-top button
- Cookie message interaction

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Intersection Observer API
- DOM Manipulation

## 📚 What I Learned

- Working with modern JavaScript events
- Event delegation and bubbling
- Creating reusable UI components
- Improving performance with lazy loading
- Using Intersection Observer for animations
- Managing DOM elements efficiently
